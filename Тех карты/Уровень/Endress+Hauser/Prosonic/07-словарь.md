# 07 · Словарь меню и терминов

| Как написано | Что означает |
| --- | --- |
| `Distance` | Расстояние от опорной поверхности датчика до отражающей поверхности |
| `Level` | Уровень относительно выбранного нуля |
| `Ullage` | Свободное пространство над продуктом в принятой системе отсчёта |
| `Empty calibration / Empty E` | Задание расстояния до нулевой отметки |
| `Full calibration / Full F` | Задание высоты рабочего диапазона |
| `Blocking distance / BD` | Ближняя зона, в которой нельзя размещать рабочую поверхность |
| `Safety distance / SD` | Зона предупреждения перед BD |
| `Tank shape` | Форма ёмкости; влияет на обработку отражений |
| `Medium property` | Свойства продукта: жидкость, сыпучая среда и т. п. |
| `Process conditions` | Характер поверхности и изменения уровня; влияет на фильтрацию |
| `Mapping / tank mapping` | Запись карты мешающих отражений |
| `Envelope curve` | Огибающая эхо-сигнала: отражения в зависимости от расстояния |
| `Output damping` | Сглаживание выходного значения, добавляющее задержку |
| `Linearization` | Преобразование уровня в другую величину, например объём |
| `Hold` | Удержание последнего значения по выбранной логике |
| `Simulation` | Проверочный режим с заданным значением вместо обычного измерения |
| `Loop-powered / 2-wire` | Питание и сигнал идут по одной двухпроводной цепи |
| `4-wire, active output` | Питание отдельно; прибор сам формирует токовый выход |
| `Passive input` | Токовый вход без собственного питания петли |
| `HART` | Цифровая связь поверх аналоговой токовой петли в поддерживающих её исполнениях |
| `FDU` | Выносной ультразвуковой датчик системы Prosonic S |
| `XA` | Дополнительные указания по безопасности, в частности для взрывоопасных зон |

Основание терминов: [T1, T2, M1, M2, S1](источники.md). Формулировки переведены и упрощены для этой базы.
