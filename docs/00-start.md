# Как учить электробезопасность

Учебный маршрут для слесаря КИПиА, который готовится к проверке знаний, включая **II группу**. Начни с терминов, затем пойми опасности, средства защиты и порядок работ. После каждой главы проговаривай определения вслух и отвечай на вопросы.

## Семь блоков

1. **Нормы:** ПУЭ — устройство; ПОТЭЭ — безопасность работ; ПТЭЭП — эксплуатация; первая помощь — отдельный приказ Минздрава.
2. **Физика:** напряжение, ток, сопротивление, мощность, переменный и постоянный ток.
3. **Опасность:** пути тока через тело, контакт, дуга, шаговое напряжение.
4. **Защита:** изоляция, ограждение, защитное заземление, автоматическое отключение, СИЗ.
5. **Организация:** роли персонала, группы, право единоличного осмотра, наряд и распоряжение.
6. **Подготовка:** отключение, запрет включения, проверка отсутствия напряжения, заземление, ограждение.
7. **Авария:** вызвать помощь, исключить опасность для себя, помощь пострадавшему по действующему порядку.

## Уровень знаний и права — разные вещи

Знать ответ на билет недостаточно для самостоятельной работы. Нужны присвоенная группа, обучение, проверка знаний, предоставленные полномочия, определённая работа и надлежащее оформление. **II группа сама по себе не даёт права самостоятельно выполнять любые работы в электроустановках.**
