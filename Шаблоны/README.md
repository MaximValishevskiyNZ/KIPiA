# Шаблоны техкарт

| Шаблон | Когда использовать |
| --- | --- |
| [Устройство](Устройство.md) | Новый прибор или семейство |
| [Пусконаладка](Пусконаладка.md) | Запись исходных настроек, проверки и итоговой конфигурации |
| [Диагностика](Диагностика.md) | Неисправность, измерения, причина и результат ремонта |
| [Источники](Источники.md) | Реестр официальных документов и связь утверждений с источниками |
| [SVG-схема](../Оформление/схема-шаблон.svg) | Редактируемый исходник рисунка |

Скопируй нужный файл в папку прибора и замени поля в фигурных скобках. Заполненный протокол конкретного объекта хранится по правилам владельца объекта; секреты и доступы в репозиторий не добавляются.
