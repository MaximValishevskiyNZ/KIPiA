# Версии для печати

- [Prosonic с поплавком: общая техкарта](Prosonic-техкарта-флотация.pdf) — обследование и проверка на каскаде флотации ТОФ.
- [Prosonic: понятное руководство](Prosonic-понятное-руководство.pdf) — техкарта, справочные разделы по моделям, схемы, диагностика, расчёты, источники и протокол.

PDF собраны из Markdown и SVG этого репозитория. В них есть закладки разделов и ссылки на электронные материалы. Электронная версия содержит алгоритмы Mermaid; в печатной версии они переданы краткими текстовыми последовательностями.

Для пересборки нужны Python 3, шрифты Noto Sans или DejaVu Sans с кириллицей и зависимости из [requirements-pdf.txt](../scripts/requirements-pdf.txt):

```sh
python3 -m pip install -r scripts/requirements-pdf.txt
python3 scripts/build_media.py
python3 scripts/build_pdf.py
python3 scripts/check_docs.py
```

После пересборки просмотреть переносы таблиц и рисунков. Изменения в тексте PDF вносятся в соответствующие Markdown-файлы, а не непосредственно в PDF.
