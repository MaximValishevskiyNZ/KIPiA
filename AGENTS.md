# Работа с базой КИПиА

- Перед изменением оформления прочитай `Оформление/ДИЗАЙН-КОД.md`; для нового материала используй `Шаблоны/`.
- Технические параметры и схемы брать из официальных документов с указанием модели, исполнения, редакции и страницы.
- Отделять факты производителя, сведения пользователя, инженерные пояснения и учебные числа.
- Не подставлять неизвестную модель, распиновку, уставки объекта или конструкцию поплавка по внешнему сходству.
- Основной материал Prosonic — общая техкарта с поплавком для флотации; точные подключения находятся в отдельных справочных разделах.
- При изменениях Prosonic обновлять связанные SVG/PDF и реестр источников. Генераторы: `scripts/build_media.py`, `scripts/build_pdf.py`.
- Перед коммитом запускать `python3 scripts/check_docs.py`; при изменении PDF просматривать страницы с изменёнными таблицами и рисунками.
- В описании изменения явно писать, была ли проверка на реальном оборудовании. Проверка источника не означает проверку на объекте.
