## 4. Что ещё необходимо для уровня нормативной энциклопедии

1. Проверить **каждое числовое требование** в актуальной редакции применимого документа, если такие значения будут добавляться.
2. Провести экспертную проверку всех утверждений с учётом специальной отраслевой и локальной документации конкретного предприятия.
3. Подтвердить сборку `mkdocs build --strict` и реальную работу поиска, меню, раскрытия ответов на телефоне.
4. Настроить GitHub Pages на публикацию ветки `gh-pages` и проверить рабочий адрес.
5. Расширять разделы по задачам по мере появления реальных билетов и моделей приборов, не выдавая единый учебный текст за официальные локальные инструкции.
